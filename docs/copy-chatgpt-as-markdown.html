How to Copy ChatGPT as Markdown (and Why the Formatting Keeps Breaking)

Updated October 2026 · 6 min read

Copy a ChatGPT answer, paste it into your notes, and the bold is gone. The headings are gone. The table is a run of words. If that started happening to you in October 2026, you are not imagining it: since the GPT-6 rollout on October 7 and 8, the copy button and plain copy-and-paste have been dropping formatting for a lot of people, and the threads on OpenAI's own forum have had no official answer so far.

This guide covers what actually works right now, from quick tricks to a proper export, and it is honest about the limits of each. It also covers the new problem nobody had a month ago: GPT-6's interactive answers, the ones with calculators, sliders and tables you can click, which simply don't copy as text.

First, what changed

ChatGPT answers are written in Markdown under the hood. Bold is **bold**, a heading is # Heading, a table is rows of |. The interface renders that into formatted text. The copy button used to hand you the Markdown, which is why pasting into Notion, Obsidian or a Markdown editor used to just work.

Two things happened in October 2026. The copy button started returning plain text, without the Markdown marks, for many users on the new interface. And GPT-6 began answering some questions with interactive widgets instead of text. A widget is not Markdown at all: it is a small program the page runs. Select it, copy it, and you get fragments.

Whether the first problem is a bug or a decision, nobody outside OpenAI knows. Plan for it to come and go.

1. The code-block trick (reliable, one answer at a time)

Ask ChatGPT to give you the Markdown source itself. Type something like:

Put your last answer inside a single markdown code block, exactly as written, so I can copy the raw Markdown.

ChatGPT wraps the answer in a code fence, and the code block has its own copy button that always copies the raw text. Paste that anywhere that understands Markdown and the headings, lists, bold and tables come back.

Good for: one answer you care about.
Bad for: a long conversation. You would be doing it twenty times, and it only works for the answer, not for your own messages.

2. Paste as rich text instead (Word, Google Docs, email)

If your destination is a word processor and not a Markdown app, you may not need Markdown at all. Select the answer in the ChatGPT page with the mouse, copy, and paste into Google Docs, Word or an email. The browser carries the formatting as rich text: bold, headings and simple tables usually survive. Check tables on arrival, they are the first thing to break.

Good for: documents and emails.
Bad for: Notion, Obsidian, GitHub, anything that wants Markdown. Rich text pasted there turns into a mess of spacing.

3. GPT-6 interactive answers: there is no copy, so take the text

When ChatGPT answers with a comparison table you can sort, a calculator with a slider, or a chart, the usual methods fail. The copy button gives you nothing useful, and selecting the widget copies labels without values. Three options, in order of effort:

  • Ask for a plain version. "Give me that as plain text with a normal Markdown table." ChatGPT will rewrite it, and then method 1 works. You lose the interactivity, which is the point.
  • Reduce visuals in settings. ChatGPT lets you turn down how often it answers with interactive elements. It is a reduction, not an off switch, but it makes plain answers more common.
  • Export the rendered text. A tool that reads what is on screen, rather than what the copy button offers, gets the values the widget is showing. That is what ThreadPort does, below.

Frequently asked questions

Why does copying from ChatGPT lose bold and italics?

Since early October 2026, the copy button and plain copy-and-paste often return the text without its Markdown marks on the new ChatGPT interface. OpenAI has not explained it. Asking ChatGPT to put the answer in a code block gives you the raw Markdown reliably.

How do I copy a ChatGPT table into Excel or Google Sheets?

Select the table with the mouse and paste into the spreadsheet: most of the time the browser carries it as a real table. If it arrives as one column, ask ChatGPT for the table "as CSV in a code block", copy that, and use your spreadsheet's paste or import for comma-separated text.

Can I copy a GPT-6 interactive answer (calculator, chart, sortable table)?

Not with the copy button, and selecting it copies labels without values. Ask ChatGPT to give the same answer as plain text with a Markdown table, or use an extension that exports the rendered text of the conversation.

Is there a free way to export a whole ChatGPT conversation as Markdown?

Yes. ThreadPort's Download .md is free with no limit and runs entirely in your browser. OpenAI's own export, under Settings, Data controls, gives you all your conversations as a zip of JSON and HTML by email, which is complete but not Markdown and not per conversation.
